🛠️ Hướng dẫn tích hợp thêm dự án mới vào source `all_in_one`

1
Thêm nút điều hướng (Tab) trong Header: <button class="aio-tab-btn" data-module="ten_du_an">Tên Dự Án</button>
2
Tạo Container Module trong `<main>`: <div id="module-ten_du_an" class="aio-module" style="display:none;">...</div>
3
Viết logic tương tác trong `app.js` hoặc file JS riêng: Hệ thống router tự động xử lý chuyển đổi giữa các module mà không gây xung đột dữ liệu.
